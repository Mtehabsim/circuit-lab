# ARENA reference and CircuitLab original curriculum

CircuitLab uses ARENA's public research challenges as a skills reference, not as source content. The current policy asks groups and organizations to request permission before running a program based on ARENA materials. CircuitLab's challenge text, data, model implementations, checkpoints, tests, and walkthroughs are independently authored and independently generated. No ARENA notebook, dataset, checkpoint, solution, or prose is bundled here. See [ARENA's materials policy](https://www.arena.education/using-our-materials) and the [ARENA Chapter 1 monthly problem index](https://learn.arena.education/chapter1_transformer_interp/monthly_algorithmic/intro/).

ARENA describes the monthly problems as practice applying the first two exercise sets (transformers from scratch and introductory mechanistic interpretability), with balanced brackets recommended. Its stated standard for a full solution includes a proposed QK/OV mechanism, causal/attribution evidence such as ablation, patching or direct logit attribution, and optional subspace or adversarial analysis. CircuitLab's mission format should preserve that depth while independently training the checkpoint under investigation.

## Palindrome mission research design

ARENA's published palindrome task is a binary classifier over token sequences, and its page describes a two-layer, two-head causal transformer with LayerNorm and no MLP. Its expected full investigation includes a QK/OV mechanism and evidence, with subspace analysis or adversarial cases as optional depth. CircuitLab will use an independently specified alphabet and dataset generator, train its own checkpoint, and make no assumption that this model learns the same mechanism. The model architecture and task description are inspired by the public challenge; the actual weights, training data, prompts, tests, starter code, grader, and walkthrough must be original.

The checkpoint passes a reproducible training/evaluation gate. The walkthrough is based on empirical exploration of this exact checkpoint and explicitly records unresolved QK/OV/path questions. Its six milestones are independently replayed: length-stratified behavior evaluation (10 points); an attention statistic on held-out raw patterns (15); a limited candidate ablation with a recomputed hidden effect (15); learner-written scaled-QK and OV tensor operations on real and synthetic inputs (25); learner-written component-output patch predictions checked on matched target/control pairs (20); and a falsifiable candidate-versus-alternative prediction tested on further hidden pairs (15). The first three total 40 points, so localization and ablation alone cannot pass the mission. The grader cannot certify arbitrary natural-language explanation; it preserves prose and tests the structured prediction instead.

The current checkpoints' measured evidence is reported in [`research/PALINDROME_REFERENCE_INVESTIGATION.md`](research/PALINDROME_REFERENCE_INVESTIGATION.md). In particular, final EOS residual patching is treated as decision localization, not an explanation of upstream computation. The UI reveals the walkthrough only after independent completion or an explicit reveal action.

## Seven-problem future coverage

The linked ARENA pages below establish task behavior and the published model configuration. The introduction page sets the shared research bar: propose QK/OV mechanisms, support them with attention plots, targeted ablation/patching or direct logit attribution, and optionally study subspaces or construct adversarial examples. CircuitLab's later references should inspect the solutions privately for research-method inspiration, then implement a separately trained model and original analysis.

| ARENA-style problem and source | Published task/model context | CircuitLab research milestones | Objective hidden checks |
|---|---|---|---|
| [Palindromes](https://learn.arena.education/chapter1_transformer_interp/monthly_algorithmic/palindromes-july-2023/) | Binary sequence classification; published model is 2 layers × 2 heads, causal attention, LayerNorm, no MLP | Characterize length/mismatch errors; inspect attention and residuals; decompose candidate QK/OV paths; test ablations and clean-to-near-miss patches; compare adversarial cases | Unseen symbol combinations, lengths in supported range, single mismatches at each mirrored offset; separately measure out-of-range failures |
| [First Unique Character](https://learn.arena.education/chapter1_transformer_interp/monthly_algorithmic/first-unique-character-august-2023/) | At each prefix, output the earliest character unique so far; `?` is both start/rest and no-unique marker. Published model is 2 layers × 3 heads with LayerNorm and no MLP; page describes it as a step up from Palindromes | Analyze token-level outputs and prefix state; track repeated/unique character representations; test candidate heads and path direction at each position; distinguish first-unique selection from simple frequency detection | Prefix lengths, no-unique prefixes, multiple uniques, repeated prefixes, characters unseen in public prompts |
| [4-Digit Sum](https://learn.arena.education/chapter1_transformer_interp/monthly_algorithmic/4-digit-sum-september-2023/) | Four-digit addition presented little-endian; published model is 3 layers × 3 heads with LayerNorm and no MLP. Page describes a more involved/creative investigation than First Unique | Analyze place-value and carry representations; inspect position-specific logit contributions; patch carry-relevant activations; test whether paths compose across digit positions | Carry chains, no-carry cases, zeros, boundary sums, operand combinations not in public examples |
| [Sorted List](https://learn.arena.education/chapter1_transformer_interp/monthly_algorithmic/sorted-list-october-2023/) | Start token, ten numbers, end token; classify ascending order at the next position. Published model is 1 layer × 3 heads with LayerNorm and no MLP | Compare adjacent-order evidence with global aggregation; inspect how values/positions enter QK and OV; test repeated values and one local inversion | Repeats, minimum/maximum values, inversions at each location, sequence value ranges supported by training |
| [Cumulative Sum](https://learn.arena.education/chapter1_transformer_interp/monthly_algorithmic/cumulative-sum-november-2023/) | Emit each prefix sum modulo 10. Published model has two layers with 3 heads then 2 heads, causal attention, LayerNorm, and MLPs | Trace running state across positions; inspect MLP and attention contributions; compare modular representations; patch earlier-prefix state and test downstream sums | Wraparound/carry, changed sequence lengths, held-out digit patterns and positions |
| [Caesar Cipher](https://learn.arena.education/chapter1_transformer_interp/monthly_algorithmic/caesar-cipher-january-2024/) | Decode a message; first two repeated characters encode the shift. Published model is 1 layer × 1 head with LayerNorm and no MLP | Determine how key information is represented and routed to each character; analyze QK/OV and position effects; patch the shift representation; distinguish key lookup from memorized decoded strings | Unseen messages, shifts, positions, and message lengths in the declared supported range |
| [Trigrams](https://learn.arena.education/chapter1_transformer_interp/monthly_algorithmic/trigrams-november-2024/) | Next-character prediction in mostly random sequences where special `(A, a, b)` trigrams occur above baseline; published model uses 53 tokens and is 2 layers × 3 heads with LayerNorm and no MLP | Establish frequency baseline; implement a trigram detector; analyze repeated-context attention and value copying; test distractors, occurrence count, and composition | Novel surrounding context, changed locations/frequencies, distractors, token patterns that do not contain a special trigram |

For each later mission, checkpoint provenance must include generator, seed, model config, training code, training metrics, in-distribution and adversarial evaluation, and documented out-of-distribution limits. Learner-facing instructions must describe the model actually shipped, not assume ARENA's circuit transfers to a new training run.
