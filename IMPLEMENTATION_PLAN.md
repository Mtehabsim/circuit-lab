# CircuitLab implementation status and plan

## Product direction

CircuitLab is a code-first research challenge platform for mechanistic interpretability. The learner runs real Python against trained models, inspects tensors, generates plots, tests interventions, and submits executable evidence. ARENA's Monthly Algorithmic Problems are the educational reference; CircuitLab's distributed content and checkpoints are original.

## Repository audit and reused infrastructure

The existing React/TypeScript/Monaco editor, FastAPI API, SQLite persistence, versioned JSON challenge store, PyTorch adapter, bounded worker/grader subprocesses, saved drafts/runs, and hidden-data split remain useful. The six original hand-constructed circuit challenges are now archived and removed from the active list. Their exact component-ID graders are not used for the Palindrome mission.

## Current limitations

- Python state starts fresh for each Run; the journal retains code, outputs, events, and plots, but there is not yet a persistent multi-cell kernel.
- The automatic score verifies intervention behavior on the supplied distribution; it cannot prove a unique prose explanation or complete mechanistic account.
- The Palindrome model does not support unrelated task capabilities, so specificity is estimated against other head interventions and intervention size rather than a second language/control task.
- Local subprocess execution is trusted-user only and is not an OS sandbox.
